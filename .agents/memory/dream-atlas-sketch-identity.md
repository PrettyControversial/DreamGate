---
name: Dream Atlas sketch identity
description: Why Dream Atlas location sketches are stable local assets rather than generated from private dream text on every view.
---

Use one stable, location-specific graphite sketch for each physical-place family in the Dream Atlas. Preserve the supplied parchment background and keep sketches inside the circular content tokens. An abstract sketch is appropriate only for a genuinely unknown place.

**Why:** A stable illustration helps people recognize the same recurring place in both the path and record; local assets avoid latency, repeated image-generation cost, and sending private dream content to an image service just to render the page.

**How to apply:** When adding a new recognized place, supply its own pencil sketch and use the same asset anywhere that place appears. If classification becomes more specific, let the token follow the new place's sketch without changing the dream-grouping rules.
